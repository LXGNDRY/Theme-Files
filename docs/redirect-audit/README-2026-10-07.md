# Redirect audit: legendary-branding.com (2026-10-07)

Scope: all 501 Shopify URL redirects (Online Store > Navigation > URL Redirects), checked against the live catalog and the live site.
Companion file: `redirect-audit-2026-10-07.csv`, one row per redirect. It is the **pre-Tier-1 snapshot** (values as of the audit, before the 2026-10-07 changes): its `target` column holds each redirect's original target, so it also serves as the rollback baseline. For the 64 rows changed by Tier 1, the live value is `new_target` in `tier1-applied-2026-10-07.csv`.

CSV columns: `source`, `target`, `live_source_status` (HTTP status of the source URL on the live site), `state`, `hops` (configured chain length, plus one where Shopify adds its own canonical `/collections/x/products/y` -> `/products/y` hop), `final` / `final_state` (the real endpoint after all hops), `action` (exactly one per row, mutually exclusive), `suggested`, `confidence` (H / M / L).

## Executive summary

- **Only 130 of 501 redirects (26%) land on a live, relevant page.**
- **173 (35%) send visitors to the homepage.** Google treats most as soft 404s; they pass no ranking value.
- **134 (27%) point at a dead page:** the product is unlisted, a draft, or deleted, so the redirect ends in a 404.
- **52 (10%) point at a live product through a collection that no longer exists.** They work but cost an extra hop.
- **9 target URL fragments** (`/#seotid...`) left by an SEO app. Servers ignore fragments, so these behave like homepage redirects.
- **2 are shadowed**: `/collections` and `/llms.txt` are real storefront routes that return 200, so those redirects never fire.
- **No redirect loops.** 3 two-hop chains, all ending on a dead page. No redirect shadows a live product.
- **Verified live:** 499 of 501 sources return a 301 whose destination matches the configured target exactly; the other 2 are the shadowed routes above.

### Specific defects

- **`/pages/ccpa-opt-out` redirects to the homepage.** A live page exists at `/pages/data-sharing-opt-out` ("Your Privacy Choices"). A privacy-choice URL landing on the homepage is a compliance risk; have counsel confirm the right target.
- **`/pages/contact-us` redirects to a `#seotid` fragment.** The live page is `/pages/contact`.
- **3 blog redirects target `/blogs/news/`**, a blog that does not exist.
- **Chains (all end dead):** `legendary-butterfly-t-shirt` -> `butterfly-tee` -> `the-savage-butterfly-tshirt`; `men-s-solid-color-...-jogger-set` -> `mens-solid-...` -> `solid-color-...`; `featured-product` -> `featured-products` -> `legendary-select`.
- **`yellow-dot-athletic-long-short` is a valid live handle** (the apparent truncation is real). `simply-goated-athletic-long-shor` is also a real handle, but unlisted.
- **Autoketing leftovers:** 7 `/pages/autoketing-sitemap*` redirects plus the 2 `/pages/html-sitemap-articles|products` redirects belong to an app that appears to be gone; `robots.txt` also disallows `/*/pages/html-sitemap`.

## Remediation plan

Every row has exactly one `action`, so tiers never overlap: apply them in order and each tier only touches rows still assigned to it.

| `action` | Rows | What to do | Risk |
|---|---|---|---|
| `KEEP` | 131 | Nothing | n/a |
| `REVIEW_SHADOWED` | 2 | Redirect never fires. Delete if not wanted; confirm `/llms.txt` content is served as intended | Very low |
| `TIER1_RETARGET` | 64 | 52 collection-prefixed targets -> canonical `/products/<handle>` (same final page, one hop fewer); 10 `neverdy-foam-trucker-hat` rows -> `/products/the-lb-hat-foam-trucker-hat`; `/pages/ccpa-opt-out` -> `/pages/data-sharing-opt-out` (confirm with counsel); `/pages/contact-us` -> `/pages/contact` | Very low / low |
| `TIER2_RETARGET_OR_PUBLISH` | 116 | Dead product, collection and page targets: retarget to the closest category (`shirts-tops`, `hoodies-jackets`, `accessories-more`) or publish the unlisted product. Needs a merchandising call | Medium |
| `TIER2_ARTICLE_DECISION` | 3 | `/blogs/news/...` targets: pick a replacement article or send to the blog index | Low |
| `TIER3_HOME_REVIEW` | 168 | Homepage redirects: delete rows with no relevant current product and no backlinks (404 is the correct answer); retarget the rest to a category. Check Search Console "Page with redirect" and backlinks first | Medium |
| `TIER3_FRAGMENT_RETARGET` | 8 | `/#seotid` rows: retarget to a category or delete | Low |
| `TIER3_DELETE_APP_LEFTOVER` | 9 | Autoketing and html-sitemap leftovers: delete | Low |

Tier 1 alone fixes 64 redirects (13%). Counts are exclusive: for example `/pages/contact-us` is in Tier 1 only, not in the fragment tier.

## Method and limits

- Redirect list: Shopify Admin GraphQL (`urlRedirects`, all 501). Catalog: `products` (113: ACTIVE / UNLISTED / DRAFT), `collections`, `pages`, `blogs`/`articles`.
- Live checks: HTTP status (no redirect following) for all 501 sources and about 100 unique targets on `www.legendary-branding.com`. Shopify serves `/collections/<missing>/products/<handle>` as a 301 to `/products/<handle>`.
- Not available: Search Console and backlink data, so there is no traffic or link-equity weighting per redirect. Tier 2 and 3 decisions should check those first.
- A product marked "unlisted" or "draft" is treated as not live because its live URL returned 404 in each case.
